Teste Front-End Econverse

Vitrine de produtos do teste técnico da Econverse. A página reproduz a seção "Produtos relacionados" do layout, consome a lista de produtos em JSON e abre um modal com os dados do produto selecionado.

## Instalação

git clone https://github.com/OLIVERPSYCHO/teste-front-end.git
cd teste-front-end
npm install

## Rodar

npm run dev      # http://localhost:5173

## Compilar

npm run build    # gera dist/
npm run preview  # serve o build localmente

## Testar

npm test         # Vitest
npm run lint     # Oxlint
npm run typecheck
